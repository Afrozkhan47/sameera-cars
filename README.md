🚗 Sameera Cars

A premium used car dealership website built for a real client using Next.js, TypeScript, Tailwind CSS, and Sanity CMS.

🌟 Overview

Sameera Cars is a modern, responsive platform that allows customers to browse verified pre-owned vehicles with a premium buying experience. The project focuses on performance, clean UI, and a seamless user experience.

✨ Features

* Responsive premium landing page
* Dynamic car catalogue
* Advanced filtering by brand, fuel type, transmission, and category
* Individual vehicle detail pages
* WhatsApp enquiry integration
* Interactive image gallery with lightbox
* Sanity CMS for inventory management
* Optimized images and animations
* SEO-friendly architecture

🛠️ Tech Stack

* Next.js 16
* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Sanity CMS
* Lucide React
* React Icons
